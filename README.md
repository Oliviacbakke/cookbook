# Olivia's Cookbook

A full-stack cookbook app for storing, organizing, and viewing recipes. It runs in the browser and as an iOS app (built with Capacitor). The backend is deployed on Render.

## Features

- Add recipes with ingredients, instructions, and a category (Main, Side, Dessert)
- Browse recipes by category from the Recipes tab
- Search by keyword, by an ingredient a recipe has, or by an ingredient it doesn't
- View individual recipe pages
- Edit and delete recipes from the Manage tab, which has its own search
- Recipe of the Day on the home page, which changes every day
- Bottom tab bar for navigation: Home, Recipes, Search, Add, Manage
- Loading and error screens with a retry button
- Optional API key so only the app can add, edit, or delete recipes

## Tech Stack

**Frontend:** React, JavaScript, CSS, Vite, React Router, Capacitor (iOS)
**Backend:** Python, Flask, Flask-CORS, gunicorn
**Database:** SQLite
**Hosting:** Render (backend)

## How to Run

### Backend

```
cd backend
pip install -r requirements.txt
python app.py
```

The backend runs at http://127.0.0.1:5000.

### Frontend

```
cd frontend
npm install
npm run dev
```

Open the local URL Vite prints. The API address is set in `src/config.js`. Use `http://127.0.0.1:5000` to talk to your local backend, or the Render URL to use the deployed one.

### iOS app

```
cd frontend
npm run build
npx cap sync ios
npx cap open ios
```

In Xcode, choose your iPhone (not "Any iOS Device"), set your Team under Signing & Capabilities, and press Run.

### API key (optional)

Set an `API_KEY` environment variable on the backend and put the same value in `src/apiKey.js`. Without it, anyone who finds the backend URL can edit or delete recipes.
